# Rail

The app's left rail (shell.tsx `AppShell`): two floating panels, the logo above ONE menu panel that runs to the window's foot, `space-rail` apart and from the page edge (docs/mock/Rail.dc.html frames 2, 2e, 4, built alpha.6; owner, 2026-11-28: "Yes, one panel").

- Width `size-rail`; each panel is a `panel` with `radius-rail` on all corners and 14px 4px padding.
- Logo panel: the mark in `on1` at 24px on the rail's tile with the 155deg `a1` to `a2` gradient, 12 / 5 corners. It links to Create. While something is down it carries the studio's state (owner, 2026-11-28; there is no status tile): a red `logo-dot` on its corner, the label "helmstudio · Runner down", and a click or Enter opens the status popover; Esc closes it (StatusTile).
- Menu panel (`Sections`), top down: Create, Magic, Gallery, Timeline, Pipelines, Models (Magic's tile `tile-magic-from` to `tile-magic-to`, wand-sparkles); a 1px × 32px `s4` rule; the Assistant (when ready, with a dot while it is closed: yellow `#f2c14e` when a card waits for you, accent `a1` (`dot new`) for an answer you have not read, 10px with a 2px `s1` ring on the tile's top-right (2026-11-28); it stays in the rail, owner 2026-11-28). Then the free space, a second rule pushed to the foot (`mt-auto`) and Setup (`Setup` group): Hub and System (admins only), then Settings.
- An item (`dock-item`): 58px wide, 56px tall, 10px apart (owner, 2026-11-28: "balance it"); a 32px gradient tile (11px corners, 10% under the shared 36px tile; white lucide glyph at 18px, stroke 1.75, `shadow-tile`) over a 10px/500 label, 5px between. Each section has its own fixed gradient (`tile-*-from` to `tile-*-to`, 155deg). Not current: the tile is desaturated (saturate 0.55, brightness 0.8) and the label is `t2`. Current (`aria-current="page"`): full colour, a 2px white 85% ring 2px out, label `t1`.
- Setup folds (`rail-gear`): on a window under about 805px an admin's Hub, System and Settings fold into one Setup tile: a wrench (lucide `Wrench`) on the Settings tile's grey, so it never looks like the Settings gear it holds (owner: "chane icon of setup"); label "Setup", `aria-haspopup=menu`, current on a setup page. A click opens the shared ContextMenu with `beside`: titled Setup, to the right of the rail (8px out), its bottom level with the tile, never over the rail's items; Hub, System, Settings with their icons, the current page ticked; arrows, Enter, Esc as every menu. A non-admin has Settings only, which never folds.
- A window under 800px scrolls the whole rail. On a phone the rail is the PhoneDock.

The consumer provides the current path and whether the viewer is an admin; labels are one word.
