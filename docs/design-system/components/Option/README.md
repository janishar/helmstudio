# Option

One of a few choices (an aspect, a size, an enum value): a 36px box with a 1px `ln` border, `radius-small`, 8px side padding, 12px text.

- Pressed (`aria-pressed="true"`): `a1` border on `s1`.
- `ln` is under 3:1 on its ground in every theme, as in the source; the pressed state is carried by the `a1` border, which meets 3:1.

The consumer provides the choice's text and its pressed state; use it in a row of 2 to 6, never alone.
