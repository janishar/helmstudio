# Panel

The four surfaces things float on. Each has three round corners and one tight bottom-left: the organic radius.

- `panel`: `s1` with a soft top sheen, `radius-panel` / `radius-panel-tail`, `shadow-panel`. The rail, the composer's base.
- `aside`: `p0`, `radius-aside` / `radius-aside-tail`, `shadow-aside`. The side panel (Inspector, a take's panel). On a window 960px and up it sits beside the page and scrolls on its own.
- `pop`: `s2`, 14px padding, `radius-pop` / `radius-pop-tail`, `shadow-pop`. Popovers, menus, the modal.
- `set`: an inspector tile, label over value: `s2` with the sheen, 10px 12px padding, `radius-pop` / `radius-pop-tail`.

Borders are not used to separate surfaces: tone and shadow do it. The consumer provides the content and padding.
