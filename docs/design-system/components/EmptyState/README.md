# EmptyState

What a list says when it has nothing to show: one plain `t2` sentence, centred, 40px above and below. No pictures, no buttons in the message.

- Empty: say what lands here and how to add it ("Nothing here yet. What you make in Create lands here; you can also upload images or drop them here.").
- Filtered to nothing: "No takes match."
- Loading: "Loading…" (`role="status"`).

The consumer provides the sentence.
