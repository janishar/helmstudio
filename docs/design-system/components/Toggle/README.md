# Toggle

An on / off switch (admin and settings pages, `sw`): `size-toggle-w` by `size-toggle-h`, pill, with a 20px knob.

- Off: `s1` track with a 1px `ln` ring, `t2` knob at the start.
- On: `a1` track, `on1` knob at the end.
- Disabled: 0.55 opacity.

Use `role="switch"` and `aria-checked`. The consumer provides the label beside it; the switch itself has no text.
