# Wave

The sound mark (`wave`): one speech-like bar shape for every sound, not the real audio ("not exact but common in all audio", owner, 2026-11-25), on `s1` with a 1px `s5` border and `radius-field`; the bars are `s4`, tiled 120px wide.

- Used for an audio take's picture (card and tile) and under a source's trim bar.
- Playback is the browser's own `<audio controls>`, full width; video plays in native controls.

The consumer provides only the box size. No waveform data is drawn.
