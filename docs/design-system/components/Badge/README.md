# Badge

Short pills that label or report state.

- Tag (`tag`): 11px/500 on `s4`, pill, 2px 8px. Accent tag (`tag-accent`): `a1` with `on1`.
- Status (`st`): 11px/600, pill, 2px 9px; plain `s4`; done `st-ok` (`a1`/`on1`); running `st-run` (`a2`/`on2`); waiting `st-wait` (1px `a1` ring, `a1` text: under 4.5:1 in parchment, 3.74 on `g` and 4.08 on `s1`, flagged); failed `st-bad` (`a2` text on `s5`: under 4.5:1 in some themes, flagged in its tokens).
- Kind badge: Music, Sound, Voice on a take card, 600 10/16, `radius-badge`, in `kind-music`, `kind-sound`, `kind-voice` with their `on-kind-*` text.

Every status carries its word; colour alone never says it. The consumer provides one or two words.
