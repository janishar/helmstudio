# Chain

A pipeline's chain on its card (Pipelines, `chain` and `pl`): its steps as pills in order.

- Chain `chain`: wraps, 6px between rows and 4px between pills, 10px padding, 12px corners, on `in`; a 12px arrow between steps.
- Step `pl`: a 24px pill with one tight corner (999 999 999 6), 0 9px padding, 11/500, one line, on `s3`.
- Kinds: the input and output `pl-io` on `s5`; a gate that waits for your pick `pl-gt`, transparent with a 1px `dash` ring; an agent step `pl-ag`, `a2` mixed 26% into `s3`, `t1` text.

The consumer provides the steps and their kinds. The step names here are examples.
