# Segmented

Tabs over one panel (Gallery Edit: Crop, Resize, Rotate, Flip, Extend, Convert): a `seg` track with 30px buttons.

- Track: `s1`, 1px `s3` border, `radius-field`, 3px padding.
- Button: 13px/500, `t2`, 12px side padding, `radius-small`; pressed `s5` with `t1`.

The consumer provides the labels (one word each) and which is pressed.
