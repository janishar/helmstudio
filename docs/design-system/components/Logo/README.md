# Logo

The helmstudio mark, Logo A "Playhead h" (kit.tsx `MarkPaths`, `Logo`; files under the Logos assets): an h whose stem carries a playhead flag, drawn on a 24 grid with 3.2 strokes.

- Sign in tile: 44px, `radius-logo` with a `radius-logo-tail` bottom-left, 155deg `a1` to `a2` gradient, `shadow-logo`, the mark in `on1` at 28px.
- Rail tile: `size-tile`, `radius-tile` / `radius-tile-tail`, the same gradient with `shadow-tile`, the mark in `on1` at 24px (the full mark's minimum).
- On a ground: arch in `a1`, stem and flag in `a2`, the word "helmstudio" lowercase in Bricolage Grotesque 700 at -0.02em in `t1`. On parchment the arch and word are ink `t1`, the stem and flag `a1`.
- Use the tokens so the mark follows the theme; the fixed-colour files are for outside the app. Never redraw it; a phone's bar shows no mark.

The consumer provides only the size. The lockup beside the mark is set in live type here; the outlined lockup is in the Logos assets.
