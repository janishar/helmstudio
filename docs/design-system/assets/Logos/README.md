# Logos

Logo A, "Playhead h", as drawn: an h whose stem carries a playhead flag, on a 24 grid with 3.2 strokes.

- `mark.svg` — the mark for dark grounds: arch lime `#b9e37a` (forest `a1`), stem and flag orange `#ff8552` (forest `a2`). On a light ground use ink `#1f1a14` and rust `#c8553d`.
- `mark-mono.svg` — one colour, drawn in `currentColor`; in an `<img>` it renders black, so set the ink by inlining it.
- `lockup-horizontal.svg` — mark plus the wordmark outlined from Bricolage Grotesque 700, for dark grounds (word `#f0f2e8`); on light the word is ink `#1f1a14`. Landing header and footer, 24px tall.
- `lockup-stacked.svg` — the mark over the word, for dark grounds.
- `app-icon.svg` — the dock tile: 155deg lime-to-orange gradient, organic radius, mark in `#17200a` (`on1`).
- `favicon.svg` — the purpose-drawn 16px cut for the browser tab.

Inside the app draw the mark from tokens (Logo component) so it follows the theme; these fixed-colour files are for everything outside it.
