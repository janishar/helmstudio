# Icons

Every lucide icon (lucide-react 1.73.0, ISC licence) the web app imports, one SVG each, named as lucide names them: 24 grid, outline, stroke 2, round caps and joins.

- Single ink: each file draws in `currentColor` with its colour set to `#f0f2e8` (forest `t1`), so it shows on the dark grounds; in an `<img>` it cannot follow the theme. In the app, use the lucide component and let it take the text colour.
- Sizes in the app: 14px in chips and small buttons, 16px in menus and dialogs, 18px on the rail's tiles (stroke 1.75 there and on the settings chip).
- `loader-circle` also serves `Loader2`, `ellipsis` serves `MoreHorizontal`, `ellipsis-vertical` serves `MoreVertical`, `square-dashed-text` is `TextSelect`, `circle-exclamation-point` is `CircleAlert`, `triangle-exclamation-point` is `TriangleAlert`, `message-circle-question-mark` is `MessageCircleQuestion`, `wand-sparkles` is `Wand2`, `trash` is `Trash2`, `eighth-notes` is `Music`, `rotate-ccw-clock` is `History`.
