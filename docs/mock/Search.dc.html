helmstudio · Search (proposed)

One search field for every list that can grow: Create’s sessions first, then Magic boards, sequences, chats, pipelines and batches, the pickers, the admin tables and the smaller lists. Each frame sits in its real screen with a note: when the field shows, what it matches, the keys, the empty, no-match and loading states, and whether the server or the browser searches. Owner, 2026-11-27: “session list can grow large give option to search in most places”. Boards only, nothing built.

0 · SearchField, one field for every long list

A new shared component (design system: SearchField, added at build time). It is the Field look with a search glyph at the left and a clear × at the right, and the placeholder says what it searches: “Search sessions”, “Search boards”, “Search batches”. It sits as the first row inside the list it searches and stays there while the list scrolls.

1 · Create, the session switcher

The session name’s ⌄ opens the Sessions popover (Main board). Today it lists the newest 100 sessions and nothing older can be reached. It gets the field at the top, older sessions by search, and Load older.

2 · Magic, the board switcher

Today the board name opens a right-click style menu with one row per board, no scroll and no search (newest 100). It becomes a popover like the Sessions one.

3 · Timeline, the Sequences dialog

The sequence name’s ⌄ opens Sequences (TimelineDialogs board). Same field, same rules.

4 · Assistant, the Chats list

The Chats button opens the list over the thread (AssistantChats). Today the newest 200 chats, titles only.

5 · Pipelines, the list and the batches

The pipelines list already has a search box; it becomes the SearchField and asks the server. Recent / All batches gets the field and a row of state chips.

6 · Pickers: Elements, Looks, Voices

These already have a search box that filters in the browser. It becomes the same SearchField and, past what is loaded (200 of your own items), asks the server.

7 · System: Users and API keys

Both tables load everything at once (not paged), so the search runs in the browser. Revoked keys never leave the list, so they hide by default.

8 · Smaller lists: the 8-row rule

Every other list that can grow gets the same field once it passes 8 rows, and none before. Drawn once here; each screen puts the field in the same place, above its table or list.
