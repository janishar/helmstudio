The frozen design, as it was written

Eleven documents from the design sprint, kept here in the form they were produced so they can be read rather than diffed. Open any of them in a browser; each page is self-contained and works offline.

These are reading copies, not the contract. The contract is the markdown in docs/design/ — it changes by pull request, and an implementation that disagrees with it is wrong by definition. These pages are a snapshot of the same material at the moment it was frozen. Where the two differ, the markdown is right and this is out of date.
