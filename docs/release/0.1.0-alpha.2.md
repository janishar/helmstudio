## As plugins

Owner, 2026-11-25: "plugin will be a design of publishing additional features that plug into the system later" and
"in our list of features move the appropriate ones in the plugins". The plugin system is item 33. Built as plugins:

- **claude-code-bridge** (model provider, personal use only): in the repo since bf08948, set up by hand today.
- **media-tools** (Assistant tools): items 11 (crop, resize, rotate, convert, trim, speed, audio) and 13 (frame
  extractor). Also take actions in the Gallery.
- **web-search** (Assistant tools): item 34.

The plugin system's first version supports two kinds only: model providers and Assistant tools (owner,
2026-11-25: "v1 for now"). Library packs come later (docs/backlog.md).

Everything else on this list changes the core (the Assistant drawer, the Mac app, Create, Gallery, the pipelines
service) and stays there.

## Temporary setup in dev (removed 2026-11-25)

The hand-made `claude-code` provider and its key file are gone: dev now uses the bridge through Plugins › Add as
provider (`claude-code-bridge-…`, the owner's own), its key in `~/.helm/claude-code-bridge.env`. The deployment's
assistant and session naming use `deepseek`; the Anthropic provider stays off (owner's choice).
