# 0.1.0-alpha.7: what goes in

Planned after 0.1.0-alpha.6. Release only from main: finished work is merged into main, the merged branches are
deleted, then the commit on main is tagged; nothing is tagged until the owner says. UI items get their board first
(docs/mock), then the build. Every code change gets a row here. Release steps: [checklist.md](checklist.md).

notes in [notes-0.1.0-alpha.7.md](notes-0.1.0-alpha.7.md). Rows 1 to 6 moved to alpha.8.
